# CPU Project

An ongoing effort to design and simulate an 8-bit CPU from the transistor level up using LTspice.

The processor will be constructed using discrete N-channel and P-channel MOSFET transistors, beginning with fundamental logic gates and progressing through increasingly complex hardware components including adders, arithmetic logic units (ALUs), control logic, registers, and instruction execution circuitry.

## Project Objectives

- Design a functional 8-bit and potentially 2 core CPU architecture
- Implement digital logic using CMOS transistor-level circuits
- Develop an 8-bit arithmetic logic unit (ALU)
- Explore computer architecture and processor design
- Document the design, testing, and verification process

## Planned CPU Components

- Logic Gates
- Half Adder
- Full Adder
- 4-bit Adder
- 8-bit Adder
- 8-bit ALU
- Registers
- Program Counter
- Instruction Decoder
- Control Unit
- Memory Interface
